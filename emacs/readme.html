1. Overview

A literate, distribution-independent configuration for Emacs 31+. It behaves identically under plain emacs and under emacs --daemon + emacsclient -c.

1.1. Tangled files

  • early-init.el — GC, native-comp, frame suppression, straight.el bootstrap.
  • init.el — everything else, in the exact order of the sections below.

1.2. Load-order contract

The tangle order is the load order. It is arranged so that a package is always configured after everything it depends on:

  1. early-init.el → straight.el + use-package + built-in package registry.
  2. Core Lisp settings (no packages needed).
  3. UI: fonts → theme → mode-line → dashboard → decorations.
  4. Completion stack: vertico → orderless → marginalia → consult → embark → corfu/cape.
  5. Evil + evil-collection + general (leader). Nothing binds Evil keys before Evil exists.
  6. Projects and files: project.el → projectile → dired family → ibuffer/tramp/vterm.
  7. Editing utilities, writing modes, Org, programming, applications.
  8. Maintenance helpers and load.d/.

1.3. Conventions

  • Every use-package form has a trigger (:hook, :bind, :commands, :mode, :after) or an explicit :demand t. Nothing depends on use-package-always-defer.
  • A feature that ships with Emacs is declared :ensure nil :straight (:type built-in).
  • A feature that ships inside another package (e.g. vertico-directory inside vertico) is declared :ensure nil :straight nil — it is NOT built-in, and marking it built-in makes straight register a bogus package.
  • Each package appears exactly once in this file.
  • Extra Elisp in load.d/ is loaded last; a failing file is reported, not fatal.

2. early-init.el

Runs before package.el and before the first frame is drawn. Everything here must be cheap and must not depend on any package except straight.el itself. 

;;; early-init.el --- Early init -*- lexical-binding: t; no-byte-compile: t -*-
;; Generated from readme.org – edit the Org file, not this one.

;; ---------------------------------------------------------------------------
;; 1. Garbage collection
;; ---------------------------------------------------------------------------
;; Raise the GC threshold so that loading ~200 packages does not trigger
;; hundreds of collections.  Restored to a sane value on `emacs-startup-hook'.
(setq gc-cons-threshold most-positive-fixnum
      gc-cons-percentage 0.6)
     
;; ---------------------------------------------------------------------------
;; 2. Cheap global defaults
;; ---------------------------------------------------------------------------
;; `vc-follow-symlinks' avoids the "symbolic link to a VC file" question when
;; the dotfiles repository is symlinked into ~/.config/emacs.
(setq vc-follow-symlinks t
      read-process-output-max (* 8 1024 1024) ; 8MB: fewer reads from LSP servers
      eval-expression-print-length 50
      eval-expression-print-level 10)
     
;; ---------------------------------------------------------------------------
;; 3. First-boot detection
;; ---------------------------------------------------------------------------
;; On the very first start no packages exist yet, so hide the frame instead of
;; showing a half-configured Emacs.  The frame is made visible again at the end
;; of startup (see init.el).
(defvar my/first-boot
  (not (file-directory-p (expand-file-name "straight/repos" user-emacs-directory)))
  "Non-nil when straight has never cloned anything on this machine.")

(when my/first-boot
  (push '(visibility . nil) initial-frame-alist))

;; ---------------------------------------------------------------------------
;; 4. PATH
;; ---------------------------------------------------------------------------
;; Emacs inherits PATH from whatever launched it, which is often not the
;; interactive shell.  Append our own directories to both `exec-path' and the
;; PATH environment variable so that subprocesses see the same thing.
(dolist (dir '("~/.local/bin"
               "~/.opam/default/bin"
               "~/.cargo/bin"
               "/usr/local/bin"
               "/usr/bin"))
  (let ((dir (expand-file-name dir)))
    (when (and (file-directory-p dir) (not (member dir exec-path)))
      (setq exec-path (append exec-path (list dir)))
      (setenv "PATH" (concat (getenv "PATH") path-separator dir)))))
     
;; ---------------------------------------------------------------------------
;; 5. File-name handlers
;; ---------------------------------------------------------------------------
;; Every `load' and `expand-file-name' consults this alist.  Emptying it during
;; startup is a large win; it MUST be restored, otherwise TRAMP, encryption and
;; compression stop working.
(defvar my--file-name-handler-alist file-name-handler-alist)
(setq file-name-handler-alist nil)

(add-hook 'emacs-startup-hook
          (lambda ()
            (setq file-name-handler-alist
                  (delete-dups (append file-name-handler-alist
                                       my--file-name-handler-alist))
                  ;; 32MB is a good steady-state threshold: large enough to
                  ;; avoid stutter, small enough to keep pauses short.
                  gc-cons-threshold (* 32 1024 1024)
                  gc-cons-percentage 0.1))
          90)
         
;; ---------------------------------------------------------------------------
;; ---------------------------------------------------------------------------
;; Native compilation: bounded, quiet, and cached
;; ---------------------------------------------------------------------------
(when (fboundp 'native-comp-available-p)
  (when (native-comp-available-p)
    ;; The current name is `native-comp-jit-compilation'; the old
    ;; `native-comp-deferred-compilation' is an obsolete alias.
    (setq native-comp-jit-compilation t)
   
    ;; DEFAULT IS 0 = HALF OF ALL CPU UNITS.  That is what saturates the
    ;; machine.  Pin it to a small number so background compilation is
    ;; noticeable but never dominant.
    (setq native-comp-async-jobs-number 2)
   
    ;; nil = do not even write the warnings log ('silent only hides the popup).
    (setq native-comp-async-report-warnings-errors nil)
   
    ;; Speed 2 is the default; 3 makes gcc much slower for little gain.
    (setq native-comp-speed 2)
   
    ;; Packages that are pointless or harmful to native-compile.
    (setq native-comp-jit-compilation-deny-list
          '("/beacon\\.el"          ; upstream defalias-in-if warning
            "/\\.dir-locals\\.el"
            "-autoloads\\.el\\'"
            "-pkg\\.el\\'"))))
           
;; ---------------------------------------------------------------------------
;; 7. Proxy
;; ---------------------------------------------------------------------------
;; Honour the usual environment variables so package cloning works behind a
;; corporate/ISP proxy.
(when-let* ((proxy (or (getenv "HTTPS_PROXY") (getenv "https_proxy")
                       (getenv "HTTP_PROXY")  (getenv "http_proxy"))))
  (setq url-proxy-services
        `(("no_proxy" . "localhost\\|127\\.0\\.0\\.1")
          (http  . ,proxy)
          (https . ,proxy))))
         
;; package.el must not initialise itself: straight.el owns the load path.
(setq package-enable-at-startup nil
      package-quickstart t)
     
;; ---------------------------------------------------------------------------
;; 8. Frame suppression
;; ---------------------------------------------------------------------------
;; Disable chrome before the first frame exists, so there is no flash of an
;; unstyled menu/tool bar.
(push '(menu-bar-lines . 0) default-frame-alist)
(push '(tool-bar-lines . 0) default-frame-alist)
(push '(vertical-scroll-bars . nil) default-frame-alist)
(setq frame-inhibit-implied-resize t
      use-file-dialog nil
      inhibit-startup-screen t
      inhibit-startup-message t
      inhibit-startup-echo-area-message user-login-name)
     
;; ---------------------------------------------------------------------------
;; 9. straight.el bootstrap
;; ---------------------------------------------------------------------------
(defvar bootstrap-version)
(let ((bootstrap-file (expand-file-name
                       "straight/repos/straight.el/bootstrap.el"
                       user-emacs-directory))
      (bootstrap-version 7))
  (unless (file-exists-p bootstrap-file)
    (with-current-buffer
        (url-retrieve-synchronously
         "https://raw.githubusercontent.com/radian-software/straight.el/develop/install.el"
         t 'silent)
      (goto-char (point-min))
      (re-search-forward "^;;$" nil t)
      (eval (read (current-buffer)) 0)))
  (load bootstrap-file nil 'nomessage))

(require 'straight)

(setq straight-recipe-repositories '(melpa gnu-elpa-mirror emacsmirror-mirror)
      straight-git-shallow-clone t
      straight-pool-size 4
      straight-build-dir (expand-file-name "straight/build" user-emacs-directory)
      straight-use-package-by-default t)
     
;; ---------------------------------------------------------------------------
;; 10. Built-in pseudo-packages  (IMPORTANT)
;; ---------------------------------------------------------------------------
;; Many third-party packages declare a dependency on libraries that ship with

        org ox ox-latex ox-html org-id

        dired dired-x dired-aux ls-lisp
        python tramp ibuffer saveplace savehist recentf autorevert
        outline which-key tab-bar tab-line completion-preview
        display-fill-column-indicator pixel-scroll

(straight-use-package 'use-package)

;; ---------------------------------------------------------------------------
;; 11. First-boot package fetch
;; ---------------------------------------------------------------------------
(defvar my/straight-first-boot my/first-boot
  "Remember the first-boot state before any package is cloned.")

(defun my/straight-first-boot-fetch ()
  "Fetch straight.el recipe repositories once, on the very first boot."
  ;; Never do this in a daemon: a synchronous pull blocks emacsclient
  ;; connections until it finishes.
  (when (and my/straight-first-boot (not (daemonp)))
    (unless (or noninteractive (input-pending-p) current-prefix-arg)
      (message "First boot: fetching straight.el recipes (this may take a moment)...")
      (run-with-timer
       5 nil
       (lambda ()
         (condition-case err
             (straight-pull-recipe-repositories)
           (error (message "First boot: recipe fetch failed: %s"
                           (error-message-string err)))))))))
                           
(add-hook 'after-init-hook #'my/straight-first-boot-fetch)

4. Core settings

Plain Lisp; no packages required.

4.1. Identity and paths

Read the identity from git so it stays in one place. Every directory used later in the file is defined here, expanded and with a trailing slash — this is the single most important invariant for avoiding path bugs. 

(defun my/git-config (key)
  "Return the git config value for KEY, or nil when git/key is missing."
  (when (executable-find "git")
    (let ((out (with-temp-buffer
                 (when (zerop (call-process "git" nil t nil "config" "--get" key))
                   (string-trim (buffer-string))))))
      (and out (not (string-empty-p out)) out))))
     
(setq user-full-name    (or (my/git-config "user.name")  (getenv "USER")  "user")
      user-mail-address (or (my/git-config "user.email") (getenv "EMAIL")
                            "user@example.com"))
                           
;; `expand-file-name' resolves "~"; the trailing slash in the argument is
;; preserved, so `org-directory' is already a proper directory name.
(setq org-directory (expand-file-name "~/Documents/org/"))

(defun my/normalise-dir (dir)
  "Return DIR as an absolute directory name with exactly one trailing slash.
Every root used by project.el, Projectile or Dired must go through this:
a root without a trailing slash is what produces `dirfile' concatenations."
  (file-name-as-directory (expand-file-name dir)))

4.2. Server

A plain emacs also starts a server so emacsclient works from other terminals. 

(defvar my/start-server t
  "Non-nil means a plain (non-daemon) Emacs also starts the server.")

(add-hook 'after-init-hook
          (lambda ()
            (require 'server)
            ;; `server-running-p' returns non-nil for a foreign server too,
            ;; which is exactly what we want: do not steal the socket.
            (when (and my/start-server (not (daemonp)) (not (server-running-p)))
              (server-start))))

4.3. GC and idle housekeeping

The previous version ran garbage-collect on focus-out-hook. Combined with super-save that meant a full GC and a disk write every time you alt-tabbed. Only the idle timer remains. 

;; Collect when Emacs has been idle for five minutes.  `t' means repeat.
(run-with-idle-timer 300 t #'garbage-collect)

;; Reap file buffers that have not been displayed for 24h.  Runs every 12h.
(run-with-idle-timer
 (* 12 3600) t
 (lambda ()
   (dolist (buf (buffer-list))
     (let ((shown (buffer-local-value 'buffer-display-time buf)))
       (when (and (buffer-live-p buf)
                  (not (buffer-modified-p buf))
                  (not (minibufferp buf))
                  (buffer-file-name buf)          ; only file buffers
                  (not (string-prefix-p " " (buffer-name buf)))
                  ;; `buffer-display-time' is nil for never-displayed buffers;
                  ;; calling `time-since' on nil used to signal an error here.
                  shown
                  (> (float-time (time-since shown)) 86400))
         (kill-buffer buf))))))

4.6. Large, remote and symlinked files

Three different situations that all deserve the same treatment: turn off the expensive machinery. The old symlink handler set eglot-managed-mode to nil with setq-local, which lies to Eglot about its own state — it now uses the real API. 

(defvar my/large-file-threshold (* 1024 1024)
  "Buffers larger than this many characters get heavy features disabled.")

(defun my/large-file-setup ()
  "Disable expensive features in very large buffers."
  (when (> (buffer-size) my/large-file-threshold)
    (display-line-numbers-mode -1)
    (font-lock-mode -1)
    (when (bound-and-true-p flymake-mode)  (flymake-mode -1))
    ;; Flycheck was previously left running on multi-megabyte buffers.
    (when (bound-and-true-p flycheck-mode) (flycheck-mode -1))
    (when (bound-and-true-p indent-bars-mode) (indent-bars-mode -1))
    (setq-local undo-fu-session-inhibit t)
    (message "Large file: heavy features disabled.")))
   
(defun my/heavy-features-off-maybe ()
  "Turn off costly integrations for REMOTE files only.
Symlinks are normal (dotfiles, straight build trees); they must NOT disable
LSP.  Previously this shut Eglot down for symlinks too, which is why
`flycheck-eglot-mode' appeared to do nothing."
  (when (and buffer-file-name (file-remote-p buffer-file-name))
    (when (bound-and-true-p diff-hl-mode) (diff-hl-mode -1))
    (auto-revert-mode -1)))
   
;; Depth 90 so these run after the major mode and its own hooks.
(add-hook 'find-file-hook #'my/large-file-setup 90)
(add-hook 'find-file-hook #'my/heavy-features-off-maybe 90)

;; Line numbers everywhere else.

5.3. Mode-line

A hand-written mode-line. Two rules govern its design:

  1. Nothing that runs a process or touches the disk may run on redraw. The mode-line is re-evaluated on every cursor move. The old version called vc-state and vc-responsible-backend there, which is a git subprocess per keystroke on large repositories.
  2. Buffer-local state is computed by hooks, and the mode-line only reads it.
;; ── 1. Language version ────────────────────────────────────────────────────
;; Probed once per (executable, directory) pair, on idle, never synchronously
;; inside `after-change-major-mode-hook'.
(defvar-local my/lang-version nil
  "Propertized language version string, e.g. \"Py 3.12.3\".")

(defvar my/lang-version-cache (make-hash-table :test 'equal)
  "Cache of (EXECUTABLE . DIRECTORY) -> version string.")

(defun my/lang-version--spec ()
  "Return (LABEL EXECUTABLE ARG...) for this buffer's language, or nil."
  (cond ((derived-mode-p 'python-base-mode)
         (list "Py" (or (and (boundp 'python-shell-interpreter)
                             (executable-find python-shell-interpreter))
                        (executable-find "python3"))
               "--version"))
        ((derived-mode-p 'rust-ts-mode 'rustic-mode 'rust-mode)
         (list "Rust" (executable-find "cargo") "--version"))
        ((derived-mode-p 'go-ts-mode 'go-mode)
         (list "Go" (executable-find "go") "version"))
        ((derived-mode-p 'js-base-mode 'typescript-ts-mode 'tsx-ts-mode)
         (list "Node" (executable-find "node") "--version"))))
         
(defun my/lang-version--run (exe args)
  "Run EXE with ARGS and return the first x.y[.z] number in its output."
  (when exe
    (with-temp-buffer
      (when (zerop (apply #'call-process exe nil t nil args))
        (goto-char (point-min))
        (when (re-search-forward "[0-9]+\\(?:\\.[0-9]+\\)+" nil t)
          (match-string 0))))))
         
(defun my/lang-version-update ()
  "Fill `my/lang-version' for the current buffer, using the cache."
  (setq my/lang-version nil)
  (when-let* (((not (file-remote-p default-directory)))
              (spec (my/lang-version--spec))
              (exe  (cadr spec))
              (key  (cons exe default-directory)))
    (let ((ver (gethash key my/lang-version-cache 'unset)))
      (when (eq ver 'unset)
        (setq ver (my/lang-version--run exe (cddr spec)))
        (puthash key ver my/lang-version-cache))
      (when ver
        (setq my/lang-version
              (propertize (format "%s %s" (car spec) ver)
                          'face 'font-lock-type-face))
        (force-mode-line-update)))))
       
(defun my/lang-version-schedule ()
  "Defer the version probe so opening a file never blocks on a subprocess."
  (let ((buf (current-buffer)))
    (run-with-idle-timer
     0.5 nil (lambda () (when (buffer-live-p buf)
                          (with-current-buffer buf (my/lang-version-update)))))))
                         
(add-hook 'after-change-major-mode-hook #'my/lang-version-schedule)

(defvar-local my/flycheck-status nil

(defun my/flycheck-update (&rest _)

;; ── 3. VC branch + file state (cached) ─────────────────────────────────────
;; `vc-mode' is a buffer-local string maintained by VC itself.  We only call
;; `vc-state' when that string changes, not on every redraw.
(defvar-local my/ml--vc-cache nil
  "Cons of (VC-MODE-VALUE . rendered string).")

(defun my/ml--vc-state-prefix (file backend)
  "Return a one-character state marker for FILE under BACKEND."
  (pcase (ignore-errors (vc-state file backend))
    ((or 'up-to-date 'edited 'nil) "")
    ((or 'removed 'conflict 'unregistered) "!")
    ((or 'needs-update 'needs-merge) "^")
    ('added "+")
    (_ "")))
   
(defun my/ml-branch ()
  "Return the VC branch plus a compact file-state marker, or nil."
  (when (stringp vc-mode)
    (if (equal (car my/ml--vc-cache) vc-mode)
        (cdr my/ml--vc-cache)
      (let* ((clean (string-trim
                     (replace-regexp-in-string
                      "\\` *[[:alpha:]]+[-:@!?\\^]" ""
                      (substring-no-properties vc-mode))))
             (backend (and buffer-file-name
                           (ignore-errors
                             (vc-responsible-backend buffer-file-name))))
             (state (if (and buffer-file-name backend)
                        (my/ml--vc-state-prefix buffer-file-name backend)
                      ""))
             (rendered (unless (string-empty-p clean)
                         (propertize (concat state clean " ")
                                     'face 'font-lock-doc-face))))
        (setq my/ml--vc-cache (cons vc-mode rendered))
        rendered))))
       
;; Invalidate the cache when the file is written or reverted.
(defun my/ml-vc-invalidate () (setq my/ml--vc-cache nil))
(add-hook 'after-save-hook #'my/ml-vc-invalidate)
(add-hook 'after-revert-hook #'my/ml-vc-invalidate)

;; ── 4. Path truncation ─────────────────────────────────────────────────────
(defvar my/ml-path-keep-tail 2
  "Number of trailing path components (including the file name) to keep.")

(defun my/ml--shrink-segment (seg)
  "Shrink directory segment SEG to its first character (two if it is dotted)."
  (if (string-empty-p seg)
      seg
    (substring seg 0 (if (string-prefix-p "." seg) (min (length seg) 2) 1))))
   
(defun my/ml-path ()
  "Return a compact path: ~/p/…/tail/dir/file."
  (let* ((raw (if buffer-file-name
                  (abbreviate-file-name buffer-file-name)
                (buffer-name)))
         (parts (split-string raw "/" t))
         (n (length parts)))
    (propertize
     (cond
      ((not buffer-file-name) raw)
      ((<= n (1+ my/ml-path-keep-tail)) raw)
      (t (let* ((idx  (max 0 (- n my/ml-path-keep-tail)))
                (head (mapcar #'my/ml--shrink-segment (cl-subseq parts 0 idx)))
                (tail (cl-subseq parts idx)))
           (concat (if (string-prefix-p "~" raw) "~/" "/")
                   (string-join head "/") "/…/" (string-join tail "/")))))
     'face 'mode-line-buffer-id)))

             (eglot-managed-p)
             (eglot-current-server))
    (propertize " LSP" 'face 'success)))

8. Projects and files

This is the section that fixes the three original symptoms.

8.1. project.el

Three independent things were wrong:

  1. Root normalisation. project-root must return an absolute directory name with a trailing slash. A root without the slash makes every downstream concat produce dirfile. The old advice only called expand-file-name, which does not add the slash.
  2. Candidate presentation. The default reader, project--read-file-cpd-relative, computes a common parent directory with (try-completion "" all-files), strips that many characters from every candidate, and re-expands the chosen one afterwards. try-completion is sensitive to completion-styles, so with orderless in the mix the prefix can be wrong — and then the strip/re-expand round trip loses a separator or a whole path segment. project--read-file-absolute skips the round trip entirely: candidates are absolute file names and what you pick is what opens.
  3. Completion category. project.el uses the project-file category, not file, so the file override never applied here (fixed in the orderless block above).
(use-package project
  :ensure nil :straight (:type built-in)
  :demand t
  :bind-keymap ("C-x p" . project-prefix-map)
  :custom

  (project-read-file-name-function #'project--read-file-absolute)
  ;; Show history entries relative to the project root, which is nicer, while
  ;; the candidates themselves stay absolute.
  (project-file-history-behavior 'relativize)
  (project-switch-commands
   '((project-find-file   "Find file")
     (project-find-regexp "Find regexp")
     (project-dired       "Dired")
     (project-vc-dir      "VC-Dir")
     (project-eshell      "Eshell")
     (magit-status        "Magit")))
  :config
  ;; Normalise EVERY root: absolute + exactly one trailing slash.
  ;; This replaces the old `expand-file-name'-only advice.
  (defun my/project-root-normalise (root)
    "Return ROOT as an absolute directory name with a trailing slash."
    (if (stringp root) (my/normalise-dir root) root))
  (advice-add 'project-root :filter-return #'my/project-root-normalise)

  ;; Treat every direct subdirectory of ~/w as a project even without a VCS
  ;; build the root from the first path component.
  (defun my/project-try-w (dir)
    "Return a transient project rooted at ~/w/<first-component> for DIR."
    (let* ((w (my/normalise-dir "~/w"))
           (d (my/normalise-dir dir)))
      (when (and (string-prefix-p w d) (not (string= w d)))
        (let ((first (car (split-string (substring d (length w)) "/" t))))
          (when first
            (cons 'transient (expand-file-name (file-name-as-directory first) w)))))))

12.3.1. Why flycheck-eglot-mode can clash with this configuration

The built-in bridge (Flycheck 38+) is flycheck-eglot-mode / global-flycheck-eglot-mode. It registers an eglot-check checker and turns Flymake off in the buffer. These are the concrete conflict sources, in order of likelihood:

  1. Name collision with the old package. The built-in mode deliberately reuses the names flycheck-eglot-mode and global-flycheck-eglot-mode. If the third-party flycheck-eglot is still in straight/repos / on the load-path, whichever loads last wins and the other's setup silently does nothing. Action: M-x straight-remove-unused-repos, and make sure no use-package flycheck-eglot form survives anywhere (including load.d/).
  2. Two owners of the same buffer's diagnostics. Eglot enables Flymake; the bridge disables it. Anything that re-enables Flymake afterwards — eglot-reconnect, a major-mode hook, or (add-hook 'eglot-managed-mode-hook #'flymake-mode) — produces duplicated or flickering diagnostics. Conversely, putting flymake into eglot-stay-out-of while the bridge is on fights the bridge's own Flymake management. Pick one owner.
  3. The symlink handler used to fake Eglot's state. The old (setq-local eglot-managed-mode nil) made eglot-managed-p return nil while the server was still running. eglot-check is only active in Eglot-managed buffers, so diagnostics vanished for symlinked files — which, with a symlinked dotfiles tree, is most of them. Fixed by using the real API.
  4. flycheck-eglot-exclusive defaults to t. In an Eglot buffer only the server's diagnostics are reported; the normal command checkers are not chained. If you expected python-ruff / markdown-markdownlint-cli2 to run alongside pyrefly, they will not. Set flycheck-eglot-exclusive to nil to chain eglot-check → flycheck-lsp → command checker.
  5. Load order. global-flycheck-mode runs on after-init-hook; eglot-ensure runs on the major-mode hook. If the bridge is enabled before Flycheck itself is loaded, the eglot-check checker is not yet defined. Enabling it from Flycheck's own :config (as above) removes the race.
  6. use-package-expand-minimally t used to strip the error-demoting wrappers, so a failure inside the bridge aborted the rest of the Flycheck block instead of being reported. Now disabled.
  7. Double display. flycheck-annotate-mode draws the message inline; flycheck-posframe draws it in a childframe; the echo area draws it again. Three renderings of the same error is not a bug but it looks like one. The configuration above keeps annotations global and posframe per-buffer; drop one if it is too noisy.
  8. eglot-autoshutdown t can tear the server down while Flycheck still has a pending check for a killed buffer. Harmless in practice (the check is discarded) but it produces "process not running" noise in *Messages*.
  9. Large-file handler. It disabled Flymake but not Flycheck, so multi-MB buffers still ran the LSP checker. Now both are disabled.
  10. Formatting overlap. Apheleia formats on save; some servers also format on save via Eglot. Only one should own before-save-hook for formatting. Apheleia is the designated owner here (rustic-format-on-save is nil).

                                ;; A bare name (no "=") unsets the variable.

14.2. Reproducibility

straight.el records exact commit hashes in straight/versions/default.el. On a new machine:

  1. Commit straight/versions/default.el (the lockfile).
  2. Restore it with M-x straight-thaw-versions after the first bootstrap.
  3. Optionally commit eln-cache/ to reuse native-compiled files — but note that .eln files are tied to the exact Emacs build, so they are invalid after an Emacs upgrade.

  1. Drop one snippet engine. yasnippet and tempel overlap almost entirely. Tempel is lighter and integrates with Corfu via cape-tempel; yasnippet has the larger snippet library. Keeping both means two TAB consumers.
  2. Drop one region expander. expreg (tree-sitter aware) supersedes expand-region in every language where a grammar exists.
  3. Consider flycheck-lsp-mode instead of the Eglot bridge for pure linting. For Ruff/Biome/Harper you get resident, incremental linting without starting a full language server. Use the Eglot bridge only where you also want completion/hover/rename.
  4. jinx instead of flyspell. Enchant-based, much faster, and it can ignore code spans and org properties. It also handles multiple dictionaries in one buffer — useful for mixed Persian/English writing.
  5. harper-ls for English prose grammar — lighter and offline compared to LanguageTool, and it plugs straight into flycheck-lsp-servers.
  6. Persian LaTeX export. With minted + pdflatex you cannot typeset Persian. A xelatex class with fontspec + bidi (or xepersian) would be needed; that also means dropping inputenc=/=fontenc for those documents.
  7. nerd-icons-completion + nerd-icons-corfu to make the minibuffer and the completion popup visually consistent with Dired.
  8. consult-dir / consult-project-extra for directory jumping inside any minibuffer prompt.
  9. dired-collapse (same dired-hacks repo) collapses single-child directory chains — pairs very well with dired-subtree.
  10. breadcrumb or treesit-context for a sticky header showing the enclosing function/class; cheaper and more accurate than which-function-mode.
  11. git-gutter → already covered by diff-hl; instead consider magit-delta for syntax-highlighted diffs inside magit.
  12. emacs-everywhere to use Emacs as the editor for any Wayland text field.
  13. Lockfile discipline. Add straight-freeze-versions to a weekly reminder and commit straight/versions/default.el; that is what makes this config reproducible across machines.
  14. A my/doctor command that checks for the external binaries this config assumes (rg, fd, git, ruff, pyrefly, wl-copy, latexmk, pygmentize, difft) and reports which are missing — most "silent" failures in this setup are a missing binary.
  15. nerd-icons font installation check via M-x nerd-icons-install-fonts on first boot; without it Dired shows tofu boxes.

17. Notes

  1. Keep this file next to init.el; my/config-org resolves symlinks, so a dotfiles checkout works. Saving it re-tangles automatically.
  2. Daemon workflow: emacs --daemon then emacsclient -c. Fonts are applied per frame; the dashboard is opened on demand with SPC d.
  3. IRC password: pass insert irc/libera.
  4. Dired single keys: d flag, D delete, c copy, r rename, m mark, u unmark, x execute, q quit, TAB subtree, S-TAB cycle subtree.
  5. Project keys: SPC p f find file (absolute candidates), SPC p d Dired at the project root, SPC p r regexp, SPC p b project buffers.
  6. Org is pinned to the built-in copy early. Do not remove that line.
  7. If a package ever fails with "Autoloading file … failed to define function", the cause is almost always a :hook or :commands naming a function that does not exist. Check with C-h f before adding a hook.
  8. After upgrading Emacs, delete eln-cache/ and run SPC c b (straight-rebuild-all); stale .eln files are a common source of impossible-looking errors.
